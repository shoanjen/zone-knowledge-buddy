# 实施计划：按《04-全功能开发规格》交付全栈 MVP（B1–B8）

## 交付定义
- 后端 M0–M9 全模块 + 前端全部页面（规格 §13），`pytest` 全绿（mock 网关）、`npm run build` 通过、`ruff` 无错
- 模型调用全部以 mock/假网关验证；`.env.example` 默认 GLM（`https://open.bigmodel.cn/api/paas/v4`，model `glm-4.6`），key 由你稍后在 .env 或设置页填入后做真实冒烟
- 当前目录非 git 仓库：开工先 `git init` + .gitignore（data/、reports_output/、.env、node_modules 等），每批次完成 commit 一次便于回滚

## 前置环境检查
`python3 --version`（≥3.11）、`uv --version`、`node -v`（≥20）；缺失即报告并停，不自行安装系统级工具。

## 关键实现决策（提前锁定）
1. **Playwright 浏览器内核本轮不下载**（体积大）：web 解析保留 trafilatura 主链与 Playwright 代码路径，ImportError 时优雅降级并显式提示，README 记录 `playwright install chromium` 补装命令。
2. **ECharts vendored**：npm 装 echarts 后复制 `dist/echarts.min.js` 到 `backend/app/report/assets/`，构建期脚本化，报告模板内联引用（禁 CDN，对齐规格 §11.2）。
3. **mock 策略**：单测/集成全走 FakeGateway 注入 + respx；不启动任何真实模型服务。
4. **前端不引入 vitest**（规格中即可选），验收 = build 通过 + 按 §15.2 用例手工走查清单随 README 交付。
5. SQLite/Chroma 全部落在 `data/`（gitignore）；测试用 tmp 目录互不污染。
