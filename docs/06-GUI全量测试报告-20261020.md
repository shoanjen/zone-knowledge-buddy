## 八、追加修复：新会话按钮"无反应"（用户反馈）

**现象**：在问答页空态（未选会话、无消息）点击"新会话"毫无可见变化，被感知为按钮失效；且输入框草稿不会随新会话清空。

**根因**：`newSession()` 仅重置 store 状态，当页面已处于空态时没有任何可观察差异；草稿是 ChatStream 内部局部状态，store 无法清理。

**修复**（`frontend/src/stores/chat.js` + `frontend/src/components/ChatStream.vue`）：
1. 草稿 `draft` 迁入 chat store，`newSession()` 一并清空
2. 新增 `sessionSeq` 重置序号，ChatStream 监听它在新会话后**自动聚焦输入框**
3. 点击后统一弹出 `已开启新会话` 成功提示，保证任何状态下都有明确反馈

**复测**：空态点击（toast+聚焦）✅ / 历史会话中点击（消息清空回欢迎页+toast）✅ / 带草稿点击（草稿清空+聚焦+toast）✅ / 建议问题按钮填入（store.draft 绑定）✅
